# Hayat AI — Language Learning Agent

وكيل ذكاء اصطناعي بيحوّل أي فيديو من TikTok أو Instagram أو YouTube لدرس لغة من الحياة الحقيقية،
وبيحفظ تقدمك بذاكرة تعليمية، وآخر اليوم بيعطيك تقرير: شو شفت، شو تعلمت، وهل إنت ماشي صح لهدفك.

## الفكرة

```
رابط الفيديو (أو ملف الفيديو إذا الرابط محجوب)
        │
        ▼
 🎬 Video Agent          ← بيجيب الصوت والترجمة الأصلية (yt-dlp + ffmpeg)
        │
        ▼
 📝 Transcription Agent  ← التفريغ باللغة الأصلية (ترجمة الفيديو، أو Whisper محلي)
        │
        ▼
 🧠 Language Agent       ← Claude: التعابير المحكية، الأفعال ونهاياتها ونطقها وزمنها، القواعد ("المكياج")
        │
        ▼
 📚 Learning Agent       ← دروس + تمارين + مراجعة ذكية (Spaced Repetition) + ذاكرة لنقاط ضعفك
        │
        ▼
 📊 Daily Report         ← آخر اليوم: شو شفت، شو تعلمت، وهل رح توصل لهدفك
```

**الفلسفة:** اللغة = كلمات + مكياج. الكلمات والتعابير الجاهزة أولًا (عشان دماغك يعبّر بشكل تلقائي بدون ترجمة)،
والقواعد بس "مكياج" بخلّيها تركب. التركيز على اللغة العامية المحكية، ونهايات الأفعال: شو نوعها، كيف بتنلفظ، وكيف بتتغير مع الزمن.
النطق مكتوب بالحروف العربية.

**الوكيل بيتعلم منك:** كل جواب غلط بيتسجل. العناصر اللي بتغلط فيها بترجعلك أبكر وأول شي،
ولكل عنصر بيختار نوع التمرين اللي بتتعب فيه أكتر. الأمر `hayat practice` بيكتبلك حوار جديد مبني على نقاط ضعفك.

## التثبيت

```bash
cd hayat-ai
pip install -e ".[all]"     # yt-dlp للتحميل + faster-whisper للتفريغ المحلي
# لازم يكون ffmpeg مثبت: https://ffmpeg.org/download.html
export ANTHROPIC_API_KEY=...   # مفتاح Claude API
```

## الاستعمال اليومي

```bash
# 1) حدّد هدفك مرة وحدة
hayat goal --daily-new 10 --daily-reviews 30 --target 1000 --by 2027-06-01

# 2) أعطيه أي فيديو
hayat add "https://www.tiktok.com/@user/video/123"
hayat add ~/Downloads/video.mp4                       # إذا الرابط محجوب
hayat add video.mp4 --transcript subs.srt --lang fr   # إذا عندك النص جاهز

# 3) اقرأ الدرس
hayat lesson            # آخر درس
hayat lesson 3

# 4) تمرّن (مراجعة ذكية)
hayat review

# 5) حوار جديد على نقاط ضعفك
hayat practice

# 6) آخر اليوم: التقرير
hayat report
```

## التقرير اليومي

`hayat report` بيعرض وبيحفظ بـ `~/.hayat/reports/YYYY-MM-DD.md`:

- 🎬 **شو شفت اليوم** — كل الفيديوهات اللي حوّلتها لدروس
- 🧠 **شو تعلمت اليوم** — التعابير والأفعال والقواعد اللي بلّشت فيها
- 🔁 **المراجعة** — عدد المراجعات، الدقة، الوقت، شو أتقنت، وسلسلة الأيام 🔥
- 🎯 **هدف اليوم** — شريط تقدم للعناصر الجديدة والمراجعات
- ⚠️ **نقاط ضعفك**
- 🏁 **الهدف الكبير** — سرعتك الحالية، إمتى رح توصل، وهل إنت على الطريق ✅ أو لازم تزيد ⚠️ (وقديش باليوم)

عنصر بيعتبر "مُتقَن" لما توصل فترة مراجعته لـ 21 يوم.

### تقرير تلقائي كل يوم الساعة 10 بالليل

Linux / macOS (`crontab -e`):

```
0 22 * * * ANTHROPIC_API_KEY=... /path/to/hayat report >> ~/.hayat/reports/cron.log 2>&1
```

## الذاكرة

كل شي محفوظ محليًا بـ `~/.hayat/hayat.db` (SQLite) — غيّر المكان بـ `HAYAT_HOME`.
الموديل الافتراضي `claude-opus-5-5` — غيّره بـ `HAYAT_MODEL`.
